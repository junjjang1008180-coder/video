# 배속 플레이어

동영상·음원 파일을 열어 **원하는 배속으로 보고 듣는** 앱입니다.
설치형 웹앱(PWA)이라 휴대폰·태블릿·PC에서 홈 화면/바탕화면에 앱처럼 설치해 쓸 수 있고, 한 번 연 뒤에는 오프라인에서도 실행됩니다.
파일은 **기기 안에서만 재생**되며 어디에도 업로드되지 않습니다.

## 주요 기능

- **배속 조절**: 0.25× ~ 4× (0.05 단위), 프리셋 0.5 / 0.75 / 1 / 1.25 / 1.5 / 1.75 / 2 / 2.5 / 3×
- **음정 유지**: 빠르게 들어도 목소리가 높아지지 않음 (끄면 테이프처럼 음정이 같이 변함)
- **남은 시간 표시**: 현재 배속 기준 남은 시간과 절약되는 시간
- **구간 반복(A-B)**, 한 파일 반복, 10초 앞/뒤 이동
- **재생 목록**: 여러 파일을 한 번에 열거나 끌어다 놓기, 끝나면 다음 파일 자동 재생
- **이어보기**: 같은 파일을 다시 열면 마지막 위치부터 재생
- 마지막으로 쓴 배속·볼륨·음정 설정 기억
- 잠금화면/이어폰 버튼 제어 (Media Session)
- 키보드 단축키 (앱에서 `?` 버튼)

| 키 | 동작 |
|---|---|
| `Space` / `K` | 재생 / 일시정지 |
| `←` `→` | 5초 뒤로 / 앞으로 |
| `J` `L` | 10초 뒤로 / 앞으로 |
| `S` `D` | 0.1배 느리게 / 빠르게 |
| `R` | 1배속 ↔ 직전 배속 |
| `1`~`9` | 속도 프리셋 |
| `A` `B` `C` | 구간 반복 A / B / 해제 |
| `F` | 전체 화면 |

지원 형식은 브라우저에 따라 다르며, 일반적으로 MP4, WebM, MOV(H.264), MP3, M4A/AAC, WAV, OGG/Opus, FLAC가 재생됩니다.

## 실행 방법

빌드 과정이 없는 정적 파일입니다. 서비스 워커(오프라인/설치 기능) 때문에 `file://`로 직접 여는 것보다 웹 서버로 띄우는 것을 권장합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 휴대폰에 앱으로 설치하기 (GitHub Pages)

1. 저장소 **Settings → Pages**에서 Source를 *Deploy from a branch*, 브랜치를 이 코드가 있는 브랜치, 폴더를 `/ (root)`로 지정
2. 표시되는 주소(`https://<사용자명>.github.io/video/`)로 접속
3. 설치
   - **Android / PC 크롬·엣지**: 상단의 `앱 설치` 버튼 또는 브라우저 메뉴 → *앱 설치*
   - **iPhone / iPad (사파리)**: 공유 버튼 → *홈 화면에 추가*

## 파일 구성

```
index.html             화면 구성
style.css              디자인 (라이트/다크 모드 자동)
app.js                 플레이어 동작
manifest.webmanifest   앱 설치 정보
sw.js                  오프라인 캐시 (서비스 워커)
icons/                 앱 아이콘
```
